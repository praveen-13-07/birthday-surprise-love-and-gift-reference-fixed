# Girlfriend photos — Page 6

These 11 images are used only inside the Page 6 **Swipe through us** photo card.

To replace them, keep the filenames exactly the same:
- `girlfriend-01.jpg`
- `girlfriend-02.jpg`
- ...
- `girlfriend-11.jpg`

Replace the files in this folder with your girlfriend photos. You do not need to edit React code.

The Page 6 background photo is separate and is not affected by these replacements.
