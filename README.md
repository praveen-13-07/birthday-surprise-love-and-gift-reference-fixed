# Birthday Surprise — Blue Neo-Brutalist Edition

A romantic interactive birthday journey built with React + Vite, Framer Motion, GSAP and Lenis.

## Visual direction
- Blue-first Romantic Neo-Brutalism
- White/paper background with black offset shadows and electric-blue blocks
- Supplied couple/character images used as soft, blurred section backdrops
- Strong blue, white, black and small pink/red accent for contrast
- Grid texture, taped notes, polaroid layers and chunky buttons
- Existing interactions retained: dodging NO button, balloons, flower bloom, memory hunt, swipe gallery, timeline, letter, gift, cake and final reveal

## Supplied photos
The 11 uploaded images are included in `public/assets/photos/` as `photo-01.jpg` … `photo-11.jpg`.
A few source images were rotated into a natural upright direction and all were resized/compressed for web performance.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Edit your content
Most text and photo captions are in `src/data/content.js`.
Replace any `public/assets/photos/photo-XX.jpg` file with your own image using the same filename to swap a memory.
